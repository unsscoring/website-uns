Website UNS (unggulnusantarasport.com) is a sports championship management platform built with Laravel 11 + Livewire 3, digitizing the full competition lifecycle: event creation, contingent & athlete registration with file uploads, multi-stage verification, and payment confirmation. Currently serving martial arts championships across Indonesia with role-based access for Superadmin, Admin, and Manager.

The platform needs to scale to handle thousands of concurrent registrants during peak tournament openings, requiring real-time queue processing, query optimization, caching, and load-balanced infrastructure. I am actively improving performance for high-traffic windows and building a live scoring module to broadcast match results in real time during tournaments. Xiaomi Mimo cloud credits would directly power this transformation — enabling scalable hosting, WebSocket infrastructure for live scoring, and proper CI/CD for rapid iteration.
